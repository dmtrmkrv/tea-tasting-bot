# Timeweb Postgres: как включить

Заполните `.env` по примеру из `.env.example`: либо укажите `DATABASE_URL`, либо отдельные `POSTGRESQL_*` переменные с хостом `10.20.0.4`, портом `5432`, именем базы и логином, после чего перезапустите бота — он автоматически соберёт движок SQLAlchemy c драйвером `postgresql+psycopg` и выведет маскированный DSN в логах.
